# Яндекс Алиса в BYDMate

Алиса - это голосовой интерфейс к уже существующим возможностям BYDMate, а не прокси к BYDMate Agent. Есть два независимых пути:

1. **Кнопка на руле** (двухкнопочная схема, `KEY_ALICE_KEYCODE`, `YandexAliceLauncher`): своя кнопка открывает Алису в Яндекс Браузере, кнопка BYDMate - локальный помощник. Микрофон одновременно у двух помощников не бывает; на время Алисы музыка приглушается до громкости 4 и возвращается при выходе. Подробности и инварианты - `docs/ALICE-RECOVERY-STATUS.md`.
2. **Мост умного дома** (этот документ): Алиса распознаёт речь, ваш Worker (`reference/alice-worker/`) ставит команду в очередь, BYDMate забирает её и выполняет.

## Схема моста

```text
Alice STT
  -> Worker (Smart Home / Dialogs)
      -> автомобильная команда      -> ActionDispatcher BYDMate (allowlist, проверки скорости)
      -> окно/люк в процентах       -> AliceApertureController
      -> маршрут / поиск / точка    -> навигационный движок BYDMate
      -> приложение, медиа          -> ActionDispatcher (app_launch, media_key, media_volume)
      -> вопрос об автомобиле       -> BYDMate Agent
      -> всё остальное              -> остаётся у Алисы
```

Для команд моста не запускаются GigaAM, внешний LLM и TTS BYDMate (кроме ответа агента на вопрос об автомобиле).

## Настройки (Настройки → Умный дом)

- «Мост с Алисой» - BYDMate опрашивает Worker; включение и выключение действуют сразу, без перезапуска.
- Адрес Worker и API-ключ.
- «Алиса может управлять машиной» - **по умолчанию выключено**.
- «Алиса может прокладывать маршруты» - **по умолчанию выключено**.
- Диагностика: какие температуры последними ушли в Worker, последняя команда и её результат, какое приложение откроется на каждую команду Алисы.

| Команды                                                                 | Нужное разрешение              |
|-------------------------------------------------------------------------|--------------------------------|
| климат, сиденья, свет, окна и люк (и в процентах), шторка, багажник     | управление машиной             |
| `vehicle.command` (свободная фраза), сырые команды старого протокола    | управление машиной             |
| `navigation.route`, `navigation.search`, `navigation.show`              | маршруты                       |
| `app.*` (в том числе «открой навигатор»), `navigation.cluster_on/off`   | не нужно                       |
| `media.*`                                                               | не нужно                       |
| `agent.query` (только автомобильные вопросы), отчёт о состоянии         | не нужно                       |

Отклонённая команда не выполняется и подтверждается Worker с ошибкой `vehicle_control_disabled` или `navigation_disabled`.

## Безопасность

- Каждая запись в машину - шаг ActionDispatcher, как в автоматизации: allowlist, запрещённые шаблоны, ограничения по скорости. Скорость для ограниченных команд читается напрямую, при неизвестной скорости команда отклоняется.
- Передний багажник - только на стоянке; задний багажник от Алисы - только при известных 0 км/ч; люк и окна не открываются выше порога или при неизвестной скорости; разблокировка дверей - существующее ограничение по скорости.
- Сырые FID через мост не принимаются: только известные действия и команды словаря BYDMate.
- **Срок жизни команды - 30 секунд.** Команда старше не выполняется и подтверждается как `expired`. Возраст берётся у Worker (`age_ms`, иначе `created_at` против `server_time`); у команды без отметок времени возраст не больше, чем прошло с предыдущего ответа Worker, а сразу после включения опроса - неизвестен, и такая команда отбрасывается. Worker со своей стороны помечает команды старше 30 секунд как `expired`.
- Команда, на которую BYDMate уже ответил (подтверждение потерялось), повторно не выполняется.

## Навигация

`Алиса, построй маршрут до аэропорта` идёт прямо в навигационный движок BYDMate (места BYDMate, Дом/Работа, геокодер). Используется навигатор из «Навигатор для маршрутов»; если фраза называет приложение («через Waze», «в Яндекс Картах», «в 2ГИС», «в Google Maps»), строится в нём. «Поехали …» нажимает «Поехали», как локальный помощник.

«Открой навигатор» - это запуск приложения: выбранный в настройках навигатор, с той же таблицей названий и тем же ручным пакетом, что у локального помощника. «Открой Google Maps» открывает Google Maps, даже если выбран Waze.

## Приложения и медиа

`Алиса, открой YouTube` ищет установленное приложение по известным пакетам, затем по подписи и части имени пакета, поэтому работают ReVanced/RVX, варианты TikTok и другие сборки.

Медиа идёт в запущенный плеер через его сессию (`media_key`, переход к следующему/предыдущему треку через transport controls), без глобальной медиа-клавиши: на прошивке V1.6 она переключает источник в штатном медиацентре.

## Reference Worker

`reference/alice-worker/` - single-car реализация для Cloudflare Worker или VPS (`server.mjs` + SQLite). Разворачивается `worker.mjs` (bridge 5.13). Основные настройки:

- `BYDMATE_API_KEY`;
- `YANDEX_CLIENT_ID`;
- `ALICE_DIALOG_TOKEN`;
- `ALICE_SMART_HOME_CARDS=full|compact|none` (по умолчанию `full`: прямые команды Smart Home строятся по опубликованным устройствам);
- `ALICE_COMMAND_TTL_MS` (по умолчанию `30000`).
