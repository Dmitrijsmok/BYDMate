# BYDMate built-in voice commands, Russian.
#
# A phrase runs offline only when it equals one phrase of this file, word for word. Anything
# else goes to the cloud agent (or gets «не понял» without it). "A и B" and "A а также B" run
# when every part is a command of this file on its own.
#
# Both the phrase and the template words are normalized the same way: lower case, ё -> е,
# punctuation out, "%" -> "процентов", number words -> digits ("двадцать пять" -> 25).
# Filler words (пожалуйста, можешь, мне, слушай, эй, спасибо, хочу, я) are dropped from the phrase
# and may not appear here.
#
# Lines ("#" starts a comment; a line starting with a space continues the previous one):
#   rule NAME: a|b|...                       alternatives, used as <NAME>
#   list NAME: forms => VALUE ; forms => VALUE
#                                            slot used as {NAME}; forms are |-separated phrases in
#                                            template syntax or number ranges like 10..49
#   range NAME: 16..30                       slot whose value is the number said
#   TEMPLATE => COMMAND                      a phrase and what it runs
#   solo TEMPLATE => COMMAND                 the same, but only as the whole phrase, never as one
#                                            part of "A и B" (a phrase without its own verb would
#                                            take the other part's verb there)
# Template syntax: words, <rule>, {slot}, [optional part], (a|b) choice, a|b at the top level.
# COMMAND: dispatch strings joined by " + ", each {slot} replaced by its value; a value of several
# symbols "a,b" repeats the command once per symbol, in that order. Built-ins:
#   TEMP +1, TEMP -1    cabin temperature one step up or down
#   VOL PAYLOAD         media volume: +1, -1, mute, unmute or a level
#   ASK QUESTION        a question answered from the car's readings, nothing runs: outside_temp,
#                       cabin_temp, soc, range, ac_temp; a value the car does not report sends
#                       the phrase to the agent
#   MUSIC               Yandex Music's personal mix («Моя волна»), as the agent's play_music
#                       starts it with no query
#   NAVIGATOR [APP]     open a navigation app, nothing routed: without APP the one chosen in
#                       «Навигатор для маршрутов», else that app (yandex, maps, waze,
#                       google_maps), as the agent's launch_app opens it
# Every template phrase has a row in app/src/test/resources/voice/ru_commands_golden.tsv.

# ---- How far an opening goes ---------------------------------------------------------------
# A side window takes the number said: 1..99 sets each named window to it (the per-door position
# fid, 主驾打开30; several windows repeat it per door), 100 is the dedicated full open (打开100,
# 全开) and 0, after «поставь … на», the dedicated close (打开0, 关闭). A fraction or «чуть» maps
# to the widest detent that does not exceed it: windows 10 (vent), 50, 100. The sunroof has only
# its detents, 7 (tilt), 50, 100: a share maps to the widest one that does not exceed it, and
# below the smallest nothing matches.

rule full: полностью|до конца|на максимум
rule half: наполовину|на половину|на половинку|до половины|на пол
rule little: чуть|чуть чуть|немного|немножко|слегка|на чуть|на немножко|на щелочку|на щелку|на проветривание
rule prep: на|до
rule pct_word: процентов|процента|процент
list frac: на треть|на четверть => 通风 ; на три четверти => 半开
# One window: {win}打开{wpct} is 打开100 at 100 and 打开0 at 0, the dedicated open / close.
range wpct: 1..100
range wset: 0..100
# Several windows: 1..99 per door, the endpoints stay the whole-set open / close.
range wspct: 1..99
list pcts: 100 => 全开
list sets: 0 => 关闭 ; 100 => 全开
list roof_pct: 7..49 => 天窗通风 ; 50..99 => 天窗打开50 ; 100 => 天窗打开100
list roof_frac: на треть|на четверть => 天窗通风 ; на три четверти => 天窗打开50

rule hud: hud|худ|проекцию на (стекле|лобовом [стекле])
<on> <hud> => 打开抬头显示
<off> <hud> => 关闭抬头显示

# ---- Drive mode ----------------------------------------------------------------------------
# Terrain modes (snow, sand, mud, mountain, smart) switch only up to 15 km/h: the dispatcher's
# gate, not the dictionary. A mode without a verb is solo: "выключи X и спортивный режим" must
# not switch sport on.

list drive: режим эко|эко режим|экорежим|экономичный режим => ECO模式 ;
    нормальный режим|режим норма|обычный режим => 普通模式 ;
    спортивный режим|режим спорт|спорт режим => 运动模式 ;
    режим снег|снежный режим => 雪地模式 ;
    режим песок => 沙地模式 ;
    режим грязь => 泥地模式 ;
    горный режим|режим горы => 山地模式 ;
    умный режим => 智能模式
(<on>|<set>) {drive} => {drive}
solo {drive} => {drive}

# ---- Questions -----------------------------------------------------------------------------
# Answered from the car's own readings. Weather, charging stations and anything longer stay
# with the agent; a question never takes part in "A и B". "сколько осталось километров" stays
# with the agent too: on a route it asks for the distance left, not for the range.

rule outside: снаружи|на улице|за бортом
rule cabin: в салоне|в машине
solo [какая] температура <outside> => ASK outside_temp
solo сколько градусов <outside> => ASK outside_temp
solo [какая] температура <cabin> => ASK cabin_temp
solo сколько градусов <cabin> => ASK cabin_temp
solo какой заряд [батареи]|заряд батареи => ASK soc
solo сколько заряда осталось => ASK soc
solo [какой] запас хода => ASK range
solo на сколько [градусов] стоит <ac> => ASK ac_temp
solo какая температура [стоит] на климате => ASK ac_temp
